# README-Pflege

Die README ist die Startseite Ihres Projekts auf GitHub. Dieses Feature erstellt und pflegt sie für Sie.

Auf Code steht „README erstellen …“ oder, wenn es schon eine gibt, „README aktualisieren …“. Das Cockpit schreibt selbst, was es sicher weiß: Download, Installation, Änderungen aus den Versionen, Hinweis zu Windows-Warnungen und Lizenz. Funktionen, Bedienung, Systemanforderungen und die Erklärung der Bibliotheken schreibt die KI aus Ihrem Code.

Sie sehen jeden Abschnitt einzeln. Wählen Sie „Übernehmen“, ändern Sie den Text vorher, wenn Sie möchten, oder wählen Sie „Überspringen“. Erst danach schreibt das Cockpit die Datei. Die alte README kommt vorher in die Sicherheitskopien.

Selbst geschriebene Abschnitte ändert das Cockpit nie. Es merkt sich in cockpit.toml, welche Abschnitte von ihm stammen. In der README selbst steht dafür nichts. Ändern Sie einen solchen Abschnitt, gilt er ab dann als Ihrer.

Die Hauptsprache steht in README.md, weitere Sprachen in README.de.md und so weiter. Oben in jeder Datei stehen Links zu allen Sprachen. Nach der Hauptsprache übersetzt die KI die übernommenen Abschnitte, und Sie sehen auch diese einzeln. Welche Sprachen ein Projekt hat, stellen Sie auf Code unter „README-Sprachen …“ ein.

Vor dem Hochladen prüft die KI, ob die README noch zu den Änderungen passt. Hat sie einen Vorschlag, sehen Sie ihn als Text. OK übernimmt ihn, Abbrechen überspringt ihn. Das lässt sich in den Einstellungen des Features ausschalten.
