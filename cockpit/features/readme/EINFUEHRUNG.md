# README-Pflege

Die README ist die Startseite Ihres Projekts auf GitHub. Dieses Feature erstellt und pflegt sie für Sie.

Auf der Projektzeile steht „README …“. Gibt es noch keine README, wählen Sie dort „README-Einstellungen …“, „README aus Ordner hochladen …“ oder „README mit KI schreiben …“. Gibt es schon eine, stehen dort „README-Einstellungen …“ und „README bearbeiten …“.

„README aus Ordner hochladen …“ übernimmt eine fertige Markdown- oder Textdatei als README.md in den Ordner Code. Auf GitHub kommt sie wie jede Änderung mit „Änderungen auf GitHub hochladen …“.

„README mit KI schreiben …“: Fügen Sie Dateien hinzu, die etwas über Ihr Programm erzählen, und schreiben Sie Infos für die README in das Feld darunter. „Von KI verfassen lassen“ schreibt die ganze README. Der Text steht danach in einem Feld zum Lesen und Ändern. Im Feld darunter schreiben Sie Verbesserungsvorschläge für die KI und lassen sie den Text noch einmal verfassen. „README ist fertig so“ speichert.

„README bearbeiten …“ zeigt die README als Text. Ändern Sie ihn selbst, oder schreiben Sie Anweisungen an die KI und wählen Sie „Von KI überarbeiten lassen“. „Die README ist fertig so“ speichert.

Was das Cockpit sicher weiß, gibt es der KI als fertige Bausteine mit: Download, Installation, Änderungen aus den Versionen, Hinweis zu Windows-Warnungen und Lizenz. Die übrigen Abschnitte schreibt die KI aus Auszügen Ihres Codes, Ihren Dateien und Ihren Infos. Geheimnisse gehen nie mit. Welche Abschnitte die README haben soll, stellen Sie in den Einstellungen des Features ein.

Vor dem Speichern kommt die alte README in die Sicherheitskopien.

Die Hauptsprache steht in README.md, weitere Sprachen in README.de.md und so weiter. Nach dem Speichern übersetzt die KI die README in die weiteren Sprachen. Sie sehen jede Übersetzung einzeln, können sie ändern und wählen „Übernehmen“ oder „Überspringen“. Oben in jeder Datei stehen dann Links zu allen Sprachen. Welche Sprachen ein Projekt hat, stellen Sie unter „README-Einstellungen …“ ein.

Setzen Sie beim Hochladen eine neue Version, schlägt das Cockpit den Abschnitt Änderungen mit der neuen Version vor, und die KI prüft, was in der README sonst fehlt. Auch sonst prüft die KI vor dem Hochladen, ob die README noch zu den Änderungen passt. Hat sie einen Vorschlag, sehen Sie ihn als Text. OK übernimmt ihn, Abbrechen überspringt ihn. Das lässt sich in den Einstellungen des Features ausschalten.
