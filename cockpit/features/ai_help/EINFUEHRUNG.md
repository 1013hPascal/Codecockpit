# KI-Hilfe

Die KI-Hilfe beantwortet Fragen zur Bedienung des Cockpits, zum Beispiel „Wie lege ich einen neuen Branch an?“ oder „Wo schalte ich Pull Requests ein?“.

Sie öffnen sie im Menü Hilfe unter KI-Hilfe oder mit Umschalt+F1. Schreiben Sie Ihre Frage in das Feld Frage und drücken Sie Enter. Sie können die Frage auch mit Strg+D diktieren.

Die Antwort steht darunter in der Liste Antwort, ein Satz pro Zeile. Sie nennt den Weg mit Tasten. Strg+C kopiert eine Zeile.

Die KI kennt die Anleitungen, die Einführungen der Features und alle Menüs, Tastenkürzel und Aktionen des Cockpits. Weiß sie etwas nicht, sagt sie das, statt zu raten.

Die KI bekommt nur Ihre Frage und Auszüge aus der Hilfe, nie Ihren Code oder Ihre Zugangsdaten. Läuft die KI außerhalb Ihres Rechners, fragt das Cockpit beim ersten Mal, ob Sie einverstanden sind.

Welche KI antwortet, wählen Sie in der Feature-Verwaltung unter Einstellungen. Vorgabe ist die Standard-KI aus der KI-Verwaltung.
