# Neuigkeiten

Nach dem Start fragt das Cockpit im Hintergrund, was sich auf GitHub getan hat. Gibt es etwas Neues, kommt eine kurze Ansage. Zum Beispiel: „Seit Ihrem letzten Besuch am 20.10.: 5 Neuigkeiten in 2 Projekten.“ Gibt es nichts Neues, bleibt es still. Der Fokus bleibt immer, wo er ist.

Das Fenster öffnen Sie im Menü Neuigkeiten mit Alt+N oder direkt mit Strg+Umschalt+N. Oben wählen Sie den Zeitraum: seit dem letzten Start, die letzten 7 Tage oder die letzten 30 Tage. Jede Zeile beginnt mit dem Projekt, dann was passiert ist, dann wer und wann.

Als Neuigkeit zählen neue Issues und Pull Requests, neue Kommentare und Reviews, neue Sterne, Forks und Releases und fehlgeschlagene GitHub Actions. Was Sie selbst geschrieben haben, zählt nicht.

Enter auf einer Zeile zeigt das Issue oder den Pull Request im Cockpit. Mit Tab kommen Sie zu den Knöpfen „Im Browser öffnen“, „Im Cockpit zeigen“ und „Schließen“.

Die Neuigkeiten der letzten 30 Tage bleiben gespeichert. So sehen Sie sie auch ohne Internet.
