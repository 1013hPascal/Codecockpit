# Ollama installieren

Ollama ist ein kostenloses Programm, mit dem eine KI auf Ihrem eigenen Rechner läuft. Dabei verlässt nichts Ihren Rechner.

## Weg 1: mit winget

1. Öffnen Sie im Cockpit ein Terminal, zum Beispiel mit „Terminal …“ auf einer Projektzeile.
2. Geben Sie ein: winget install Ollama.Ollama
3. Drücken Sie Enter und warten Sie, bis „Fertig.“ kommt.

## Weg 2: von der Webseite

1. Öffnen Sie im Browser die Seite ollama.com/download.
2. Laden Sie die Version für Windows herunter und starten Sie sie.
3. Folgen Sie dem Installationsprogramm.

## Danach

1. Öffnen Sie im Cockpit das Menü KI, KI-Verwaltung.
2. Wählen Sie „Neue Text-KI einrichten …“ und dann „Lokal: Ollama auf diesem Rechner“.
3. Mit Tab kommen Sie zu den vorgeschlagenen Modellen. Das empfohlene passt zu Ihrem Arbeitsspeicher.
4. Enter öffnet das Terminal mit dem Befehl zum Herunterladen. Er läuft erst, wenn Sie Enter drücken.
5. Nach dem Herunterladen schließen Sie das Terminal und wählen das Modell.

Das Cockpit startet Ollama bei Bedarf selbst und beendet es beim Schließen wieder, wenn es Ollama selbst gestartet hat.
