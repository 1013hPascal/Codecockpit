# Checkliste Filter und Zeichen für Offenes

Tragen Sie bei jedem Punkt [x] für OK oder [!] für ein Problem ein. Unter „Ergebnis:“ ist Platz für Ihre Anmerkung.

Starten Sie das Cockpit aus dem Ordner Code\listenfilter. Gut ist, wenn ein Projekt etwas offen hat (eine geänderte Datei) und ein anderes nicht auf GitHub ist.


## Filter

[ ] 1. Zeile „Anzeigen“
Tasten: Pos1, dann dreimal Pfeil runter.
Ansage: „Neue Projektsammlung“, „Projekt vom Rechner hinzufügen“, „Projekt von GitHub herunterladen“, „Anzeigen: Alle Projekte“.
Ergebnis:

[ ] 2. Auswahl öffnen
Tasten: Enter auf „Anzeigen: Alle Projekte“.
Ansage: Ein Menü mit „Alle Projekte“ (angehakt), „Mit offenen Sachen“, „Auf GitHub“, „Mit Release“, „Nur auf dem Rechner“.
Ergebnis:

[ ] 3. Mit offenen Sachen
Tasten: Pfeil runter bis „Mit offenen Sachen“, Enter.
Ansage: „Mit offenen Sachen, … Projekte.“ Die Zeile heißt „Anzeigen: Mit offenen Sachen, … Projekte“. Darunter nur Projekte mit Offenem.
Fokus: Auf der Zeile „Anzeigen“.
Ergebnis:

[ ] 4. Sammlungen mit Filter
Tasten: Mit Pfeil runter durch die Liste, eine Sammlung öffnen (Pfeil rechts).
Ansage: Zum Beispiel „Sammlung Web, 1 von 3 Projekten“. In der Sammlung nur die passenden Projekte. Sammlungen ohne passendes Projekt fehlen.
Ergebnis:

[ ] 5. Escape im Menü
Tasten: Enter auf „Anzeigen“, dann Escape.
Ansage: Nichts ändert sich.
Ergebnis:

[ ] 6. Die anderen Filter
Tasten: Nacheinander „Auf GitHub“, „Mit Release“, „Nur auf dem Rechner“ wählen.
Ansage: Jeweils die Zahl. „Auf GitHub“ zeigt auch Repositories, die nur auf GitHub liegen. „Mit Release“ nur Projekte mit einer Exe im Release-Ordner. „Nur auf dem Rechner“ nur Projekte ohne GitHub.
Ergebnis:

[ ] 7. Bleibt nach Neustart
Tasten: Einen Filter wählen, Cockpit beenden und neu starten.
Ansage: Die Zeile nennt denselben Filter.
Ergebnis:

[ ] 8. Projekt kommt dazu
Tasten: Filter „Mit offenen Sachen“. In einem Projekt ohne Offenes eine Datei ändern, dann Strg+R.
Ansage: Keine Ansage. Das Projekt steht danach in der Liste, die Zahl in der Zeile „Anzeigen“ ist um eins höher. Die Markierung bleibt, wo sie war.
Ergebnis:


## Zeilen und Zeichen

[ ] 9. Pull Requests und Reviews in der Zeile
Tasten: Auf einem Projekt mit offenem Pull Request.
Ansage: Die Zeile endet zum Beispiel mit „1 offener Pull Request, 1 Review angefragt“.
Ergebnis:

[ ] 10. Zeichen für das Auge (nur mit Blick auf den Bildschirm)
Tasten: Liste ansehen.
Ansage: Nichts Neues. Vor Projekten mit Offenem stehen Zeichen: ● geändert, ↑ nicht hochgeladen, ↓ auf GitHub neuer, PR, R. Im dunklen Modus von Windows sind sie hell.
Ergebnis:
