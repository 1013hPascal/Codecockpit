# Checkliste Einrichtungsassistent, überarbeitet

Tragen Sie bei jedem Punkt [x] für OK oder [!] für ein Problem ein. Unter „Ergebnis:“ ist Platz für Ihre Anmerkung.

Starten Sie das Cockpit aus dem Ordner Code\einrichtungsphase. Den Assistenten öffnen Sie im Menü Einstellungen mit „Einrichtungsassistent …“. So bleibt Ihre Einrichtung erhalten. Wenn Sie dort etwas speichern, ändert es Ihre echten Einstellungen.


## Knöpfe

[ ] 1. Reihenfolge der Knöpfe
Tasten: Auf einer Seite mit Überspringen, zum Beispiel Git, mehrmals Tab bis zu den Knöpfen.
Ansage: Zuerst „Weiter“, dann „Überspringen“, dann „Zurück“, zuletzt „Abbrechen“.
Ergebnis:

[ ] 2. Erste und letzte Seite
Tasten: Auf der ersten Seite und auf der Zusammenfassung Tab bis zu den Knöpfen.
Ansage: Erste Seite: nur „Weiter“ und „Abbrechen“. Zusammenfassung: „Fertig“, dann „Zurück“, dann „Abbrechen“.
Ergebnis:


## Willkommen

[ ] 3. Was Sie erwartet
Tasten: Den Assistenten öffnen, mit Pfeil runter lesen.
Ansage: „Willkommen bei CodeCockpit.“, „In diesem Programm erwartet Sie:“, dann kurze Stichpunkte. Die ersten beiden: „Die wichtigsten Aktionen für Ihre Code-Projekte, ganz ohne Terminal“ und „Volle Funktionalität mit integriertem Terminal und intelligenter Unterstützung“. Die letzte Zeile: „Videos: erstellt mit Google NotebookLM“.
Fokus: Im Text.
Ergebnis:

[ ] 4. Knopf für das Video
Tasten: Tab, noch einmal Tab.
Ansage: Zuerst „Kurze Einführung anschauen, Schalter“, dann „Weiter“.
Ergebnis:

[ ] 5. Video abspielen
Tasten: Auf „Kurze Einführung anschauen“ Enter.
Ansage: „Das Video wird geöffnet.“ Ihr Videoprogramm startet das Video „Code-Projekte barrierefrei und mit KI verwalten“.
Ergebnis:

Ergebnis:

[ ] 7. Auswahl
Tasten: Tab.
Ansage: „Speicherart“, dann die markierte Möglichkeit.
Ergebnis:


## Git und Code-Plattformen

[ ] 8. Git
Tasten: Weiter.
Ansage: „Schritt 3 von 8: Git“. Die Liste nennt „Git ist installiert.“ und „Gefundenes Git-Programm: …“ mit dem Ort.
Ergebnis:

[ ] 9. Code-Plattformen wählen
Tasten: Weiter.
Ansage: „Schritt 4 von 8: Code-Plattformen wählen. Wählen Sie Ihr Git-System aus, das Sie verwenden möchten.“ Die Liste „Git-Systeme“ hat „GitHub“ mit Kontrollkästchen, angehakt.
Fokus: In der Liste auf GitHub.
Ergebnis:

[ ] 10. Keine Plattform
Tasten: Leertaste, damit GitHub nicht angehakt ist. Weiter.
Ansage: Die Seite „Code-Plattformen einrichten“ entfällt. Es geht weiter mit „Schritt 5 von 7: Projekte-Hauptordner“. Mit Zurück kommen Sie wieder auf „Code-Plattformen wählen“. Dort GitHub wieder anhaken.
Ergebnis:

[ ] 11. Code-Plattformen einrichten
Tasten: Mit GitHub angehakt Weiter.
Ansage: „Schritt 5 von 8: Code-Plattformen einrichten. Nun können Sie Ihre Code-Plattformen einrichten.“ In der Liste „GitHub, noch nicht eingerichtet“ oder „GitHub, eingerichtet: …“. Ist noch nichts eingerichtet, heißt der Knopf „Weiter (1 nicht eingerichtet)“.
Fokus: In der Liste.
Ergebnis:

[ ] 12. GitHub einrichten
Tasten: Enter auf GitHub.
Ansage: Das Fenster „Neues Konto: GitHub“. Beim Lesen mit Pfeil runter kommen nach „Im Browser anmelden, empfohlen. So geht es:“ drei Schritte: „1. Im Browser mit GitHub anmelden.“, „2. Bei der Code-Verifizierung den Code mit Strg+V einfügen. Er liegt schon in der Zwischenablage.“ und „3. Ganz unten auf Autorisieren klicken, auf Englisch Authorize.“
Ergebnis:

[ ] 13. Anmeldung im Browser
Tasten: „Im Browser anmelden …“.
Ansage: Das Fenster nennt den Code, „Der Code ist schon in die Zwischenablage kopiert.“ und „Wählen Sie ganz unten auf der Seite Authorize, auf Deutsch Autorisieren.“
Ergebnis:

[ ] 14. Ergebnis mit Git-Identität
Tasten: Nach der Anmeldung mit Pfeil runter und Tab durch die Seite.
Ansage: Liste „Ergebnis“ mit „Angemeldet als …“. Mit Tab: „Anzeigename“, „Git-Name für Commits“, „Git-E-Mail-Adresse für Commits“, „Anonyme GitHub-Adresse übernehmen“, „Speichern“.
Ergebnis:

[ ] 15. Anonyme Adresse
Tasten: Enter auf „Anonyme GitHub-Adresse übernehmen“.
Ansage: „Adresse übernommen: …@users.noreply.github.com“.
Fokus: Im Feld Git-E-Mail-Adresse.
Ergebnis:

[ ] 16. Speichern
Tasten: Alt+S oder Enter auf „Speichern“.
Ansage: „Konto … angelegt.“
Fokus: Wieder in der Liste „Plattformen“ auf der Seite „Code-Plattformen einrichten“. Die Zeile heißt jetzt „GitHub, eingerichtet: …“, der Knopf nur noch „Weiter“.
Ergebnis:

[ ] 17. Weg mit Token
Tasten: Nur wenn Sie mögen: Enter auf GitHub, „Mit Token anmelden …“, Token einfügen, Speichern.
Ansage: Nach dem Test der Verbindung kommt dieselbe Seite „Angemeldet“ mit „Verbindung geklappt, angemeldet als …“ und den Feldern für die Git-Identität. Die Knöpfe auf der Token-Seite: „Verbindung testen“, „Speichern“, dann „Zurück zur Auswahl“.
Ergebnis:


## KI

[ ] 18. Text der Seite KI
Tasten: Weiter bis zur Seite KI, mit Pfeil runter lesen.
Ansage: Zuerst „Um Ihren Alltag zu vereinfachen, gibt es mehrere KI-Features …“. Danach der Stand, „Arbeitsspeicher Ihres Computers: …“, die Empfehlung für die Text-KI und darunter die Empfehlung für die Sprach-KI, dann lokale KI, externe KI oder Firmen-KI, ohne KI, und „Die KI können Sie auch später noch einrichten und anpassen.“
Ergebnis:

[ ] 19. KI einrichten
Tasten: Tab zu „KI einrichten …“, Enter.
Ansage: Fenster „KI-Verwaltung“. In der Liste „Text-KI und Sprach-KI“ stehen „Neue Text-KI einrichten …“ und direkt darunter „Neue Sprach-KI einrichten …“. Mit Tab kommt „Rechner und Empfehlung“ mit „Arbeitsspeicher Ihres Computers: …“ und beiden Empfehlungen.
Ergebnis:

[ ] 20. Sprach-KI
Tasten: Pfeil runter auf „Neue Sprach-KI einrichten …“, Enter.
Ansage: Das Fenster „Sprach-KI“ mit den Whisper-Modellen. Nach dem Schließen steht der Fokus wieder in der Liste.
Ergebnis:

[ ] 21. KI-Einstellungen speichern
Tasten: Tab bis zum letzten Knopf.
Ansage: „KI-Einstellungen speichern“ statt „Schließen“. Enter schließt das Fenster, der Fokus steht auf „KI einrichten …“. Im Menü KI, KI-Verwaltung heißt der Knopf weiter „Schließen“.
Ergebnis:


## Zusammenfassung

[ ] 22. Liste
Tasten: Weiter bis zur Zusammenfassung, mit Pfeil runter lesen.
Ansage: Zuerst „Perfekt, Sie haben folgende Tools eingerichtet:“. Dann, was eingerichtet oder übersprungen ist, zum Beispiel „Eingerichtet: GitHub-Konto: … Git-Identität: …“. Die letzte Zeile: „Mit Tab gelangen Sie zu den Tipps, zum Video und zu Fertig.“
Ergebnis:

[ ] 23. Tipps
Tasten: Tab, dann mit Pfeil runter lesen.
Ansage: Liste „Tipps für den Start“: „Für einen perfekten Start hier noch ein paar Tipps.“, der Hilfe-Assistent mit den Beispielen „Wo finde ich welches Menü?“ und dem Git-Befehl, wie Sie ihn öffnen, und der Hinweis auf das Video Git für Anfänger.
Ergebnis:

[ ] 24. Video Git für Anfänger
Tasten: Tab, Enter auf „Video Git für Anfänger anschauen“.
Ansage: „Das Video wird geöffnet.“ Das Video startet.
Ergebnis:

[ ] 25. Fertig
Tasten: Tab zu „Fertig“, Enter.
Ansage: Der Assistent schließt sich, das Cockpit ist wieder da.
Ergebnis:
