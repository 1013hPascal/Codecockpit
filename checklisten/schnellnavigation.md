# Checkliste Schnellnavigation, Befehlssuche, Tastenhinweise

Tragen Sie bei jedem Punkt [x] für OK oder [!] für ein Problem ein. Unter „Ergebnis:“ ist Platz für Ihre Anmerkung.

Starten Sie das Cockpit aus dem Ordner Code\schnellnavigation.


## Schnellnavigation

[ ] 1. Zugeklappt keine Schnellnavigation
Tasten: Auf einer zugeklappten Projektzeile die Menütaste.
Ansage: Das Kontextmenü „Aktionen“ wie bisher, ohne Schnellnavigation. Escape schließt.
Ergebnis:

[ ] 2. Ausgeklappt zuerst die Schnellnavigation
Tasten: Projekt mit Pfeil rechts ausklappen, Menütaste.
Ansage: Erster Eintrag „Schnellnavigation Tagebuch, Untermenü“. Darunter die Aktionen.
Ergebnis:

[ ] 3. Einträge der Schnellnavigation
Tasten: Pfeil rechts in das Untermenü, mit Pfeil runter durchgehen.
Ansage: „Hilfe, mit der KI chatten …“, „Tastenbefehle …“, „Projekt verwalten …“, „Repository verwalten …“, „Branches verwalten …“, „Releases verwalten …“.
Ergebnis:

[ ] 4. Auch auf Zeilen darunter
Tasten: Pfeil runter auf „Releases“, Menütaste.
Ansage: Wieder zuerst „Schnellnavigation Tagebuch“.
Ergebnis:

[ ] 5. Fenster öffnen
Tasten: In der Schnellnavigation „Branches verwalten …“, Enter.
Ansage: Das Fenster „Branches verwalten“. Nach dem Schließen steht die Markierung auf der Zeile Repository.
Ergebnis:

[ ] 6. Releases verwalten
Tasten: In der Schnellnavigation „Releases verwalten …“.
Ansage: Der Fokus springt in die Aktionen der Zeile Releases, zum Beispiel „Releases neu einlesen“.
Ergebnis:

[ ] 7. Geht nicht
Tasten: Bei einem Projekt ohne GitHub „Repository verwalten …“.
Ansage: „Das geht bei diesem Projekt nicht, zum Beispiel ohne Repository auf GitHub.“ Die Markierung steht auf der Zeile Repository.
Ergebnis:


## Befehlssuche

[ ] 8. Öffnen
Tasten: Strg+K.
Ansage: Das Fenster „Befehl suchen“, Fokus im Feld „Suchen“.
Ergebnis:

[ ] 9. Suchen und wählen
Tasten: „verwalt“ tippen, dann Pfeil runter und hoch, ohne das Feld zu verlassen.
Ansage: Bei jedem Pfeil der Treffer, zum Beispiel „Projekt verwalten …“ oder „Menü KI: KI-Verwaltung …“.
Ergebnis:

[ ] 10. Ausführen
Tasten: Einen Treffer wählen, Enter.
Ansage: Die Aktion oder der Menüpunkt startet, zum Beispiel das Fenster KI-Verwaltung.
Ergebnis:

[ ] 11. Keine Treffer
Tasten: „xyz“ tippen, Enter.
Ansage: „Keine Treffer.“ Das Fenster bleibt offen. Escape schließt.
Ergebnis:


## Tastenhinweise

[ ] 12. Auf einer Projektzeile
Tasten: Auf einer Projektzeile Strg+F1.
Ansage: „Tasten hier: Pfeil rechts oder Enter klappt auf, Tab führt zu den Aktionen, Menütaste öffnet das Kontextmenü mit der Schnellnavigation.“
Ergebnis:

[ ] 13. Auf anderen Zeilen
Tasten: Strg+F1 auf „Anzeigen: …“, auf der Zeile Repository und in der Aktionsliste.
Ansage: Jeweils der passende Satz, zum Beispiel „Enter öffnet die Auswahl …“.
Ergebnis:

[ ] 14. Liste der Tastenkürzel
Tasten: F1.
Ansage: Die Liste nennt auch „Befehl suchen, … Strg+K“, „Tasten … ansagen, Strg+F1“ und die Schnellnavigation.
